THE GAMES ARE OVER

Drag tributes into the bin · faster drops build the combo · keys 1-8 switch player

Players

Up to 8 players. Click a player's name tag (or press 1–8) to make them the active scorer. Turn mode rotates players every 30 seconds so everyone gets a go on the same screen.

Tributes

One person per line. Optionally add a photo URL after a pipe, e.g.
Julia | https://example.com/julia.jpg
Photos must be hosted somewhere the page can load them (or a file in this repo, e.g. photos/julia.jpg).
